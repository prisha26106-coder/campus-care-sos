🚀 Campus Deployment Instructions

Step 1: Host the Website

Deploy the campus_emergency_prototype.html file to any hosting platform:

  • Vercel / Netlify — Free, instant HTTPS URL in 2 mins.
  • GitHub Pages — Free with university GitHub Education Pack.
  • University IT Server — Ask the campus web host team to give a subdomain like campuscare.lpu.edu.in.
Step 2: Update the URL & Print

Once you have the live URL, paste it in the "SOS Website URL" field at the top of this page. The QR codes will auto-regenerate.

Then click "🖨️ Print All QR Posters". Use a colour printer for best results. Print on A4 and laminate for outdoor or washroom placements.

Step 3: Post Across Campus
  • Hostel room doors & floor corridors (at eye level).
  • Common washrooms & bathrooms (most frequent emergency location).
  • Dining hall entrance, gym locker rooms.
  • Library security desk and study pods.
  • Each block's notice board and lift panel.
